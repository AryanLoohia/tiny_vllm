⚗

Continuous Batching

Token-level scheduling: free batch slots refill the instant a request finishes, keeping hardware utilisation high vs static batching.

⚙

Serving Modes

Switch between sequential (batch=1), static (fixed group), and continuous to see the throughput difference live.

🎚

Scheduler Policies

FIFO, Shortest-Job-First, and Priority queue ordering — compare average waiting time under mixed workloads.

🗂

Radix Prefix Cache

Shared-prefix KV cache. Reuses keys/values across prompts that share a common head (e.g. system prompt), skipping re-prefill of the shared portion.

✂

Chunked Prefill

Long prompts are split into fixed-size chunks processed one per step — lower peak memory and better TTFT interleaving.

⚡

Speculative Decoding

A small draft model proposes K tokens; the main model verifies them in one forward pass. Multiple tokens per step when the draft is accurate.

🔧

Quantization

Toggle fp32 / fp16 / int8 weights and compare speed, memory and quality.

📈

Live Observability

Throughput, batch-size, queue-depth and memory timeseries + per-request Gantt + KV-cache memory bars.

📊

Sweep Suite

One-click ablations over chunk size, batch size, and concurrency — produces comparison tables and bar charts.

How to use this lab
1. Live — tune config, send prompts, watch real-time charts.
2. Compare — run the serving-mode and speculative-decoding head-to-head benchmarks.
3. Sweeps — ablate chunk size, batch size, concurrency; find the sweet spots.
4. Phases — inspect the Gantt timeline and completed logs.
5. Hover any label for an explanation of what it measures.
